## Risk

关键任务：涉及认证、权限、Token 吊销、日志敏感数据与初始化 SQL。必须有失败/边界场景和至少一路独立复审。

## Scope

允许修改本仓库 `internal/`、`templates/`、`README.md`、必要依赖文件；Pi 维护方案、任务书与交接。禁止修改 admin、模块缓存、全局环境；禁止读取真实凭证及 `.env`、`.env.local`、account 文件。临时产物仅放 `/tmp/taurusx-*`。

### 原定安全范围

按 `docs/安全审计.md` T2 清单落实：

1. 关闭配置明文打印；访问/操作日志不得泄露密码、Token、验证码等敏感值；禁止记录验证码明文；数据库日志避免输出敏感 SQL 参数。
2. `/admin/option/*` 按实际用途落实权限与最小返回字段，避免泄露用户手机号、邮箱、IP。
3. 保护系统角色；非超级管理员不得给自己或别人分配超级管理员身份，不得通过创建/修改角色伪造系统角色或破坏系统角色。
4. 登出吊销当前 Token；禁用/删除用户、重置密码、本人改密使对应旧 Token 失效。认证依赖 Redis 出错不能放行，恢复后正常认证可用。
5. RefreshToken 不再从 URL query 获取 Token；同步前端调用（如有）。
6. 挂载必要限流，覆盖登录、验证码发送/验证、前端错误上报；限制请求大小；不信任客户端任意提供的 X-Real-IP。
7. JWT 密钥无配置、过短或弱默认值拒绝启动；补写登录成功/失败日志；pprof 默认关闭。

### 用户已确认附加范围

1. 每次生成使用独立随机初始管理员密码，CLI/生成 README 提供一次性初始化指引；不增加首次登录强制改密功能。
2. `.env.example` 不携带可直接使用的 JWT 密钥，明确要求用户在本地配置；实际密钥不写入版本库。
3. 修复部门未填写编码时第二次创建失败；保留非空编码唯一约束，并同步初始化 SQL 与必要模型/校验。
4. 已登录普通用户可修改自己的密码，不依赖管理他人权限；保持他人账号操作的权限边界。
5. 清理 downloads 的前端代理及 ignore 残留；清理已发现的 Vue 文件 EOF 多余空行。

### 不做

不改 admin；不做纯 HttpOnly Cookie 迁移、Cookie 配置统一、bcrypt 迁移、操作日志结果字段改造、CRUD 生成器；不引入新的管理平台或复杂状态机。实现若需要扩大范围，先停止报告。
